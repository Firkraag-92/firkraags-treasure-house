# 知识条目模板

## 结论速览

- 本页提供新建条目的可复制骨架。
- 模板顺序固定，不要调换；缺证据时宁可留「待验证项」，也不要编结论。

## 适用版本

- 6.1 魔改引擎（罡星煞曜传）`Ekd500.exe` / `Ekd5.exe`。

## 已确认事实

- 知识库的七章节结构见 [知识库规范](知识库规范.md)。
- 每个条目必须能回答：**这个结论能不能直接拿去做补丁？**

## 实现/使用方法

复制下面骨架新建文件：

```markdown
# 标题

## 结论速览

- 2–5 条最关键、最可执行的结论。
- 标清哪些能直接用于补丁，哪些只是线索。

## 适用版本

- 默认：6.1 魔改 `Ekd500.exe`（112 关）/ `Ekd5.exe`（117 关）。
- 其它版本：写清版本与能否迁移。

## 已确认事实

- 只写本地反汇编或实机确认过的事实。
- 地址、字段偏移、调用约定必须精确到字节。

## 实现/使用方法

- 挂钩点原文字节 → 改写字节。
- 洞穴地址与布局、断言条件。
- 生成脚本路径、产物 md5、改动字节数。

## 风险与边界

- 会影响哪些调用者、哪些界面、哪些补丁。
- 已知取舍与不能覆盖的情况。

## 证据来源

- 本地：`相对/路径/文件.md`，证据等级：已验证 / 待证 / 废弃。
- 关联专题：`../03-机制详解/xxx.md`。

## 待验证项

- 缺什么实机或静态验证。
```

## 风险与边界

- 骨架里的占位文字必须替换成真实结论，不能带着示例进正式条目。
- 「参考了别的引擎」不能作为证据等级，只能作为线索。

## 证据来源

- 体例来源：既有曹操传知识库的 `知识条目模板.md`；内容口径来源：本库规范。

## 待验证项

- 无（模板页本身不需要实机验证）。
