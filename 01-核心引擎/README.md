# 01 · 核心引擎

> 引擎的骨架：段布局、三套地址、调用约定、挂钩纪律、剧本指令分派。

## 这一层讲什么

这一层回答「代码在哪、怎么进去、进去以后栈是什么样」，是写任何补丁的前置知识。

核心判断：这支 exe 的扩展逻辑大量不在 `.text`，而在 `.data2` / `.data3` 里以可执行代码形式存在 —— 在 `.text` 里搜不到功能是常态。
