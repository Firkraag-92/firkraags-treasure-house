# 调用约定与地址语义

## 结论速览

- 这支引擎混用三种调用约定：KOEI 底座多为 **stdcall**（`ret N` 自己清栈参数），小白狐扩展多为 **thiscall 变体**（`ECX` 传 `this`，其余走栈，`ret` 或 `ret 4`），另有**裸寄存器调用**（`EAX` 传值，`plain ret`）。
- 判断依据只看函数尾部：`ret` = 无栈参数；`ret 4`/`ret 8`/`ret 0x18` = 几个双字参数。
- 地址有三套：文件偏移、RVA、VA。段表里给的是 **RVA**（`.text` 的 VA 是 `0x401000`，不是 `0x1000`）。
- VA→文件偏移必须先 `rva = VA - 0x400000` 再与段表 `VirtualAddress` 比较；直接拿 VA 比会误命中最后一段。

## 适用版本

- 6.1 魔改 `Ekd500.exe`（112 关）/ `Ekd5.exe`（117 关）。

**地址换算（117 关基底实测）**

| 段 | VA | 文件偏移公式 |
|---|---|---|
| `.text` | `0x401000` | `file = VA - 0x400C00` |
| `.rdata` | `0x486000` | `file ≈ VA - 0x400A00`（以段表 raw 为准） |
| `.data2`(1) | `0x4CE000` | `file = VA - 0x42E800` |
| `.data2`(2) | `0x526000` | `file = VA - 0x42E800` |
| `.data3` | `0x626000` | `file = VA - 0x42E800` |

> 例：VA `0x5C0198` → 文件 `0x191998`；VA `0x639000` → 文件 `0x209800`；VA `0x62B200` → 文件 `0x1FCA00`。

## 实现/使用方法

**写挂钩前先确认三件事**

1. 被调用函数的尾部是 `ret` 还是 `ret N`（决定你要不要自己清栈）。
2. 参数里有几个是**指针**（`ret 4` 只意味着丢弃 1 个双字，不代表只有 1 个参数被传）。
3. 函数返回值的落点在 `EAX` 还是 `EDX`（`0x408D38` 把列传号放在 **EDX**，EAX 只是自身编号）。

**脚本里不要硬编码「文件偏移 = VA - 常数」**

用段表算：

```python
def va2off(va, secs):
    rva = va - 0x400000
    for name, vsize, vaddr, rawsize, rawptr in secs:
        if vaddr <= rva < vaddr + max(vsize, rawsize):
            return rva - vaddr + rawptr
    raise ValueError("not mapped")
```

**取段名必须 `split(b"\0")[0]`**

`.data2`/`.nodata`/`.rsrc` 的段名域 8 字节里有非 NUL 尾随字节，`rstrip(b"\0")` 会得到 `.data2 Î` 这类脏名，凡按段名过滤的脚本会**静默跳过两个 .data2 段**（共 1.5 MB 可执行代码/数据表）。

## 风险与边界

- `0x40BE7D` 会 clobber `EDX`/`ECX`；在洞穴里调用它之后不能假定 ECX 还是 `this`。
- `0x40620F`/`0x4061E4` 把结果放在 **ECX** 而不是 EAX，误用会读到上一个值。
- `0x45F670` 返回的是**记录首 dword**（编号），不是指针差。
