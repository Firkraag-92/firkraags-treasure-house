# 02 · 数据结构

> 内存里到底有什么：单位记录与战场对象、扩展行、全局数组、三个定长数据文件。

## 这一层讲什么

改动几乎都会落到这些结构上：谁是谁的指针、步长多少、哪个字段是哪个语义、能不能扩容。

最容易犯的错是把「单位记录（`0x48`）」和「战场对象（`0x24`）」互相喂错函数 —— 表现为静默返回垃圾值。
