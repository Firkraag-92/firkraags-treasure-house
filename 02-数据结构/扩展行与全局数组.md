# 扩展行与全局数组

## 结论速览

- **扩展行** = `0x5E0000 + 编号×0x40`（`0x40` = 64 字节），是小百狐给 6.1 加的「每单位附加数据」，异术/特技、招式、成长档全在这里。
- 它**没有**「从文件整块加载」的代码 —— 只靠剧本 `72 16` 写入 + 存档恢复。
- 全引擎对 `0x5E0000` 的立即数引用只有 6 处，读取统一走 `0x40620F`（38 个调用点）。
- SP、状态标志、变量表、名字覆盖表都是「按编号线性寻址」的全局数组，扩容会连锁影响。

## 适用版本

- 6.1 魔改（罡星 112/117 关）。

## 已确认事实

**扩展行布局（`0x40` 字节）**

| 偏移 | 内容 |
|---|---|
| `+0x00`–`+0x1C` | **15 个 word（字段 0..14）**，写入器按 `字段*2` 落点 |
| `+0x1E` | word（字段 15） |
| `+0x20` | byte 招式（字段 16） |
| `+0x21` | byte 秘术（字段 17） |
| `+0x22` | byte 合技（字段 18） |
| `+0x23` | byte **异术/特技**（字段 19） |
| `+0x24`/`+0x25` | byte（字段 20/21） |
| `+0x26..` | 五维成长档 / 兵力档 / 策略档 / 移动力 / 攻击范围等 |

- 写入器 `0x4D4270`（72/16）：字段 `<0xF` → word 到 `+字段*2`；`≥0xF` → byte 到 `+字段+0x10`。
- `0x4D4380`（72/17）是部队数据写入器，尚未逐行拆。

**按编号寻址的全局数组**

| 地址 | 大小 | 内容 | 备注 |
|---|---|---|---|
| `0x4CEA00` | dword | 单位记录基址 | 运行期 `VirtualAlloc`，非静态数据 |
| `0x501000` | 1024 word | S 形象（战场图形） | 编辑器写，file `0xD2800` |
| `0x501B00` | 0x100 | 每单位标志块 | 5 处引用 |
| `0x501C00` | 1024 byte | **SP 数组** | 紧邻变量表，扩容动它必炸 |
| `0x502000` | 4×N | **剧本变量表**（`vN`） | 紧随 SP |
| `0x50F800` | 1024 word | R 形象（头像/地图小人） | 编辑器写，file `0xE1000` |
| `0x510D00` | 48 项 × 16B | **改名覆盖表**（word 编号 + 名字槽） | 每项首 word 初值 `0x400` |
| `0x5E0000` | 1024 × 0x40 | 扩展行 | 本文主角 |

**扩展行读取点**

- `call 0x40620F` 共 **38 处**；已见到的偏移：`0x00/0x02/0x04/0x06/0x08/0x0A/0x0C/0x0E`（`0x52970B` 连续 7 个 word 各 +1）、`0x12`(word)、`0x1F`、`0x20`、`0x21`、`0x22`、`0x23`、`0x24`、`0x25`、`0x28`、`0x37`、`0x38`、`0x3F`。
- ⇒ 字段 10..14（`+0x14..+0x1C`）的用途**未全部确认**，是新功能的候选位。

## 实现/使用方法

**用扩展行存自定义数据（推荐）**

1. 选一个「无读者」的 word 字段（先从 `+0x14..+0x1C` 里挑，需逐个核对 38 个读取点）。
2. 剧本写：`72 16 <编号> <字段号> <值>`。
3. 读取：在洞穴里 `push 编号; call 0x40620F; movzx eax,word[ecx+偏移]`。
4. 好处：随存档走、不改数据结构、编辑器不用改（编辑器只编辑它认识的字段，其它字段原样保留）。

**SP 上限/读取**

- 上限函数 `0x4D40D0(EAX=编号)`：`min(等级*2 + 0x30, 200)`，同时把结果写全局 `0x505F74`，返回 SP 字节地址。
- 读 SP：`0x424810(ECX=单位指针)` → `0x45F670` 取编号 → `0x501C00+编号`。
- 扣光 SP：`0x442AA7(EAX=编号)` 减去当前上限。

## 风险与边界

- `0x501C00`（1024 B）、`0x502000`（变量表）首尾相接：把名册扩到 2048 就必须同时搬这两块，且剧本变量编号会重排 ⇒ 用户的工程全废。
- 扩展行没有文件加载路径 ⇒ 若某功能必须「默认就有」（不靠剧本），只能挂钩读取端做假值（张顺天运就是这么做的）。
- `0x510D00` 的 strcpy（`0x47FC7D`）**不做长度检查**，名字超约 14 字节会串写到下一项。
