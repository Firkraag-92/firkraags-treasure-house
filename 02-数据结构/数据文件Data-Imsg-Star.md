# 数据文件 Data.e5 / Imsg.e5 / Star.e5

## 结论速览

- 三个数据文件都是「定长记录 + 固定基址」结构，**引擎按记录号直接 `seek` 读**，没有索引表。
- `Data.e5`：人物/部队表（`0x20` 步长 × 1024 槽，从 `0x18C` 起）+ 地形适性表（`0xA8A4`，40 行 × 60 B）。
- `Imsg.e5`：全部说明文本，`0xC8`（200 B）一条；**列传 = 记录 `0x39A + 人物编号`**。
- 追加新记录只需在文件末尾接上，旧偏移不变 ⇒ 安全。改已有记录长度 ⇒ 全表错位，绝对禁止。

## 适用版本

- 6.1 魔改（罡星）。6.5PL 的 Imsg 结构相同但容量不同（2250 条）。

## 已确认事实

**Data.e5（罡星 117 关：78,936 B）**

- 人物/部队表：`0x18C` 起，`0x20` 一条，1024 槽，到 `0x818C` 结束（之后是下一张表）。
- 字段：`+0x00` 名字 8 B GBK、`+0x0D` word 编号、`+0x0F`/`+0x10`、`+0x11`=`0xFF`、`+0x12..+0x17` 六项数值、`+0x1A` 在部队模板里是兵种 id。
- 现用 986 条、编号 0..530；混有部队/NPC 模板（枪兵、侍女、酒馆、铁匠）。
- ⚠ `+0x1A` 对**人物**更像头像编号（林冲/吴用/穆弘全为 24），名将兵种是**按关在剧本里指定**的。
- 地形适性表：`0xA8A4`，40 行（=兵科 0..39）× 60 B（前 30 适性 + 后 30 消耗），`255` = 不可通行。

**Imsg.e5**

- 罡星原版：440,600 B = **2203 条 × 0xC8**；扩充版（117 关现役）：528,000 B = 2640 条。
- 记录读取器 `0x40BF56(buf, idx)`：`seek idx*0xC8` → `ReadFile 0xC8` → `byte[buf+0xC8]=0`。
- 列传包装 `0x40BFDB(buf, id)`：`id < 0x400` 才继续，`idx = id + 0x39A`，读完后转码（罡星 `0x4179A5`）。
- 策略/道具说明区起点 `0x15F90`（= `0x39A + 108` 记录处），与列传区部分重叠。
- 已占用情况（罡星原版）：0..255 非空 169、256..767 非空 134、768..1023 非空 83、**1024..1280 非空 236**、450..921 策略说明区 211。
- ⇒ 新增列传只能追加到 **1281 号之后**；扩容需同时放宽两处 `cmp 0x400`（`0x40BFE7` 与情报窗 `0x4784AD`）。

**Star.e5**

- 附加数据文件，结构与 Data.e5 类似（`System.ini` 里被形象指定器列为「Data附加文件」）。
- 本库目前只确认它存在、被编辑器读写，未展开字段。

**文件打开方式（决定能否外部热改）**

- `0x418F5C(fileobj, filename, mode)` → `CreateFileA(name, access, share=1(FILE_SHARE_READ), 0, OPEN_EXISTING, 0x80, 0)`。
- 句柄 `0x4AE4BC` 全程常开，只共享读 ⇒ **游戏运行时外部进程写不进这些文件**。
- 全引擎 `WriteFile` 只有 `0x419261`（通用写封装）与 `0x483E05` 两处 ⇒ 引擎自己也不写 Imsg，所谓「随剧情改列传」是**换指向**不是改文字。

## 实现/使用方法

**追加 Imsg 记录（安全做法）**

```python
old = open("Imsg.e5","rb").read()
assert len(old) % 200 == 0
new_records = [...]                    # 每条 200 字节，GBK + 补 0
open("Imsg.e5","wb").write(old + b"".join(new_records))
```

记录号 = `len(old)//200 + k`；列传可用号 = 记录号 − `0x39A`。

**追加后还要放宽上限**

- exe `0x40BFE7` 的立即数（`cmp eax,0x400`）：`0x400 → 0x800`（只改立即数第 2 字节，`0x40BFE9`）。
- 情报窗 `0x4784AD` 同类判断（若走的是重定向路径则不必改）。

**改地形适性**

- 直接改 `Data.e5` 的 `0xA8A4 + 行*60` 段；行号 = 兵科，**不要**改 exe 里的运行时副本（它是运行期从文件装填的）。

## 风险与边界

- 用户的剧本编辑器按固定偏移读 Data.e5 ⇒ 人物表布局一动，编辑器全废（已明确否决扩容路线）。
- Imsg 记录超 200 字节（GBK 100 汉字）会被截断，写入前要按句子边界截。
- `0x15F90` 策略说明区与列传区有重叠，追加记录时不要覆盖到 1280 之前。
