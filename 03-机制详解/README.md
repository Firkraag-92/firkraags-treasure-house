# 03 · 机制详解

> 把引擎的一个个功能拆开：伤害、地形、SP、异术特技、天运圣水、状态特效。

## 这一层讲什么

每页都是「入口函数 + 关键地址 + 口径 + 可挂钩点」的组合，目标是让你能直接照着改。

口径类结论（例如 `0x0A` = 100% 适性、`SP += 攻击力/10 + 4`）都经过实机或反汇编双向确认。

## 阅读顺序

- 按你要改的功能直接跳对应页；`伤害结算` 与 `异术与特技` 两页最长，也最常被引用。
- 每页的「风险与边界」比「已确认事实」更该先看。
