# 天运与圣水机理

## 结论速览

- **天运（80/0x50）= 五维成长基数 +2**，作用于武力/统率/智力三项；成长量 = `(基数 + 个人档位) >> 1`（档位 <6 才折半）⇒ 每级多得 1 点，高成长档多得 2 点。
- **圣水（75/0x4B）= 地形替换**：浅滩/沼泽 → 适性 110%→`0x0B`、消耗 1；大河 → 适性 `0x0C`(120%)、消耗 1。**不改地形号、不改形象**。
- 两者都是「谓词 + 覆盖返回值」的写法，不改表、不影响他人。

## 适用版本

- 6.1 魔改（罡星 112/117 关）。

## 已确认事实

**天运**

- 谓词 `0x43D4A0(unit, 0x50)`。
- 成长函数 `0x52D000`（`ECX`=单位，`[ebp+8]`=项号，`ret 4`）：
  ```
  v = 0x4072F2(ECX, 项号)
  if 0x43D4A0(unit,0x50):
      项号 0/1/2 → add dword [ebp-8], 2
  ```
- ★陷阱：无天运时 `je` 直接跳到 `cmp ecx,2`，但此时 `ECX` 是 `0x43D4A0` 内部 `0x40620F` 留下的扩展行指针（`0x5E0000+…`）≠2，所以**第三项 +2 也只在有天运时发生**（官方 xls 只写「攻防」，代码是三项）。
- `0x4072F2`（`ret 4`）：项号 >4 → 0；`movzx eax,byte[eax+ecx+0x21]`；阈值表 `0x407320 = 01 46 50 5A 64 FF…`（1/70/80/90/100）→ 返回第一个 `v < 表[i]` 的 i。
- 成长公式 `0x4073BC`（`ret 8`）：档位 `0x5B1400(unit, idx)`，`idx<=4` 时走 `0x408A60`/`0x52D000`；`cmp 档位,6; jae skip` 否则 `add al,档位; shr al,1`。
- 5 个调用点：`0x407430`、`0x407D3C`、`0x408B18`、`0x436E26`、`0x47817F`。

**圣水**

- 函数 `0x52C600`（`ret 0x10`）：`[ebp+8]`=适性（出参 EAX）、`[ebp+0xC]`=消耗（出参 EDX）、`[ebp+0x10]`=单位、`[ebp+0x14]`=地形。
  ```
  if 0x43D4A0(unit,0x4B) or 0x4CF2CA(unit):   ; 4CF2CA = 装备特效 0x2A
      地形 9/10 → 适性 0x0B, 消耗 1
      地形 7/13 → 适性 0x0C, 消耗 1
  ```
- 同函数兄弟分支：攀山（0x4A）地形 2/3/4 → `0x0C`+1；长驱（0x49）地形 0/1 → `0x0C`+1。
- 唯一调用者 `0x43F7B9`（见 [地形适性](地形适性与移动消耗.md)）。

**形象**

- `0x45362B`（兵科→形象组）：`cmp al,0xD; jae → al += 0x1A; else al *= 3`；`cmp al,0x26` 再按等级档加 0/1/2。**全程与地形无关**。
- 全 exe 里 `cmp al/cl/dl, 0x0C|0x0D` 只有 13 处，无一处做「水地形→换船形象」。

## 实现/使用方法

**给某人加天运**

两种做法：
1. 剧本写 `72 16 <编号> 19 80`（若该关还没写过 19 字段）。
2. 引擎侧补：挂钩 `0x43D4A0` 让特定编号无条件返回 1（张顺就是这么做的，因为该存档的 `+0x23` 是 0）。

**给某人加圣水/地形加成**

在 `0x43F8B4`（6 字节）判编号后调整 `[ebp-0xC]`（适性），见案例 [张顺专属天运](../10-制作案例/张顺专属天运.md)。

## 风险与边界

- 只挂 `0x43F8B4` 时，「界面显示」与「移动消耗」可能不一致（`0x411100` 直接读表）。
- 圣水/攀山/长驱走的是同一条覆盖链：**叠加顺序**是先圣水覆盖，再由 `0x412790/0x412830` 修正（六军/恶路）⇒ 同时拥有圣水与六军时结果是「圣水优先」。
- 天运的 +2 是加在「成长基数」上，不是直接加属性；看不到立竿见影的数字变化，要靠升级验证。
