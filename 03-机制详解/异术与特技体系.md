# 异术与特技体系

## 结论速览

- 异术与特技**共用同一个字节字段**：扩展行 `+0x23`（字段 19），一人一个值。
- 名字表 `0x4F0BA0`（指针数组，0..0x7E）用前缀区分类别：`【招式】`1..30、`【秘】`31..48、`【合】`49..63、`【特】`/`【异】`64..107。
- 实测：**异术 34 条**（编号 64..107 里的 `【异】` 项）、**特技 10 条**；全游戏 101 人有异术、52 人有特技。
- 授予方式是剧本 `72 16 <编号> 19 <值>`；异术是**剧情按关授予**，不是人物固有属性。
- 判定谓词 `0x43D4A0(单位, 技能号)` 循环查 `+0x23/+0x24/+0x25` 三个槽。
- 情报窗只认 `0x3F < v < 0x7F`，越界显示【无】。

## 适用版本

- 6.1 魔改（罡星 112/117 关）。

**情报窗链路**

- getter `0x5C3B50`（+0x23）→ 渲染器 `0x5C3BCA..0x5C3E20` 判 `0x3F < v < 0x7F`，越界 `xor eax,eax` → 名表[0]【无】。
- 同名族 getter：`0x5C3BB0`(+0x20 招式，`0<v<0x1F`)、`0x5C3B90`(+0x21 秘术，`0x1E<v<0x31`)、`0x5C3B70`(+0x22 合技，`0x30<v<0x40`)。
- 控件号：招式 `0x5AB`、秘术 `0x5AC`、合技 `0x5AD`、特技&异术 `0x5AA`；说明文本控件 `0x804`（走 `Imsg.e5` 的 `0x15F90 + ([0x4BE000]-1)*0xC8`）。
- ★情报窗 id 映射与旧文档 42.4 不同（罡星轮转）：`+0x20` 0..0x1F → 0x5AB；`+0x21` 0x1F..0x31 → 0x5AC；`+0x22` 0x30..0x40 → 0x5AD；`+0x23` 0x3F..0x7F → 0x5AA。

**判定谓词**

- `0x43D4A0`（`ECX`=单位，`[ebp+8]`=技能号，`ret 4`）：`0x40620F` 取扩展行后循环 3 个槽 `byte[eax+ecx+0x23]` 比对。
- `0x528990` 更严（再查 `byte[ecx+0x25] >> 1` → `0x437896`）。
- `0x4CF398`（`ECX`=单位，栈 `特效号,C,B,A`）是**装备特效**判定，与异术无关。

## 实现/使用方法

**统计/查询**

```python
# 扫全部剧本里的 72/16/field19 写入
# 正则： 72:信息传送 16 (d+) 
 19 
 (d+)
```

**给某人加异术**

剧本写 `72 16 <编号> 19 <值>`；新值要在名表里已有，否则显示【无】。

**新增一条异术（不推荐逐人硬编码）**

1. 名表：把某个占位项（如 108）改成新串指针，或新增串到空槽。
2. 说明：`Imsg.e5` 对应记录写说明文本。
3. 效果：在挂钩点用 `0x43D4A0(unit, 新值)` 判定，而不是逐人写 `编号==X`。

## 风险与边界

- 名表指针数组只到 108（之后指针错位成垃圾），直接用 `v > 108` 会读到乱串。
- `0x40BE7D` 只能吃单位记录，喂战场对象返回垃圾。
- 异术是剧情授予 ⇒ 同一人在不同关卡值可能不同，静态表只能反映「剧本写过的最大值」。

## 实现层全表（2026-10-21 补充）

> 完整版见 `117关工作目录\_exe分析\异术与特技_实现分析.md`（281 行），本节只记结论。

- **三个槽**：扩展行 `+0x23`/`+0x24`/`+0x25` 都能装技能（剧本字段 19/20/21）；判定 `0x43D4A0` 连查三格，但情报窗 getter `0x5C3B50` 只读 `+0x23`，后两个槽的效果生效但界面不显示。
- **说明文本**：Imsg.e5 记录 `450 + id`（偏移 `0x15F90 + id*0xC8`），64..107 全部有官方说明，108 起是列传。
- **判定三件套**：`0x43D4A0` 纯判定；`0x528990` = 判定 + 运气/2 概率（经 `0x437896`、随机表 `0x508F38`）；`0x4CF398` 装备特效。
- **数值层**：`0x5C5000`–`0x5C5530` 每 0x30 字节一个函数、共 29 个，全是「有技能→返回常数，否则转问装备特效」。没有函数指针表，全部直接 call。常数：星魁 1、钩镰 50、六军 10、飞刀 10、百出 99、伏虎 5、其余多为 1。
- **特技缓存标志**：11 个字节 `0x52CA00`–`0x52CA0A`（神威攻/守、疾火、暴戾、杀星、义勇攻/守、咆哮、佛宗攻/守、御风）；写入 `0x52C8B5`–`0x52C99C`，清零 `0x52CB00`，播报 `0x52CB30`。**只搜 `0x43D4A0` 会漏掉这 8 个特技的效果**。
- **效果落点（按类）**：
  - 伤害：`0x52C6xx`–`0x52CFxx`（蛮勇 0x528B60、义勇 0x528E56、无双 0x52C200、神机 0x43D3D0、神威 0x52CD00/0x52CE00、105/106/107 在 0x52C400/0x52C440/0x52C480）
  - 一套「最终伤害」函数：`0x5B0800`（佛宗 ×2/×0.5、不殆 0x5B0A40、御风 归零）
  - 状态：星魁 `0x40336A`、疾火 `0x528559`、暴戾 `0x528578`
  - 地形/移动：`0x52C600`（长驱/攀山/圣水）、`0x412790`/`0x412830`（六军）、`0x412BEA`（飞刀）
  - 其它：暴击 0x5C0A60、二击 0x528347、反击双击 0x5289F0、MP 1 点 0x44DF54、克制 130/70 0x52C000、天运 0x52D000
- **可直接启用的空位**：79 红莲业火、102 梨花乱、105 铜墙铁壁、106 不屈、107 掎角——代码齐备，剧本 `72 16 <编号> 19 <id>` 即可。
- **信息上限**：id 必须 `0x3F < v < 0x7F`（情报窗渲染器 0x5C3BCA），名表只到 108。
