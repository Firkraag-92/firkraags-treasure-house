# 必杀与集气（SP）

## 结论速览

- **必杀 = SP 满即可触发**；演出/结算后由 `0x442AA7` **把 SP 扣光**（减去当前上限）。
- **集气**：每次行动 `SP += 攻击力/10 + 4`；带『SP 获取加倍』装备特效时翻倍；上限 `min(等级*2 + 0x30, 200)`。
- SP 存 `0x501C00 + 单位编号`（1024 字节），上限值缓存在全局 `0x505F74`。
- 跨关不清空的根因：引擎里**有一个只清场的函数 `0x415ACB`，但全文件没有任何引用**（小白狐写了却没接上的死代码）⇒ SP 从来没人清，新敌人复用同一编号就继承上一关的满槽。

## 适用版本

- 6.1 魔改（罡星 112/117 关）。

## 已确认事实

**存储与上限**

- SP 数组 `0x501C00 + 编号`；15 处立即数引用：`0x40CC6E`、`0x40D14B`、`0x411023`、`0x419F8B`、`0x419FFA`、`0x41A085`、`0x424819`、`0x442AAB`、`0x479565`、`0x481117`、`0x4CFFB9`、`0x4D40FE`、`0x4D41F9`、`0x5B0CC9`、`0x5C0844`。
- 上限全局 `0x505F74`（6 处引用：`0x401E31`、`0x40CC69`、`0x4143B3`、`0x442AB0`、`0x4CFFC1`、`0x4D40F9`）。
- 上限函数 `0x4D40D0`（`EAX`=编号，`plain ret`）：
  ```
  imul edx,edx,0x48; add edx,[0x4cea00]
  mov dl,byte[edx+0x2c]          ; 等级
  imul edx,2; add edx,0x30; cmp edx,0xc8; jb → 0xc8
  mov [0x505f74],edx
  add eax,0x501c00               ; 返回 SP 字节地址
  ```
- 旧版残留 `0x40CC40`：`等级*2 + 0x3A`、上限 255，**全文件无调用者**。

**必杀判定与消耗**

- SP 是否满：`0x4143A0`（无参）→ `0x4D40D0([0x500E95])` 取 SP 与上限比较，满返回 1。
- 另一处满判定 `0x401E23`（ret 4）：`cmp al,[0x505F74]; jae → 返回 1`，未满再走 `0x40658F`/`0x44F9A9(1)`/`0x405DCF`。
- 必杀演出/结算 `0x465FA1`（ret 8）在 `0x465FE4` 调 `0x442AA7` 扣光，随后 `0x465FE9` 清 `0x500E9A`、`0x465FF1` 写 `byte[0x501bf9]=5`。
- 扣光函数 `0x442AA7`（`EAX`=编号）：`sub byte[0x501C00+编号], byte[0x505F74]`。调用者：`0x406E1E`、`0x411297`、`0x465FE4`。

**集气**

- `0x4D4160`（`ECX`=单位指针，`[ebp+8]`=编号）：
  1. 先查 `0x505FDC`、`0x500E9B`、`0x54067F` 三个标志，任一非 0 直接返回 0（不集气）。
  2. `0x4061F9` 取记录 → `0x4D4A30` 判定 → `0x4066E0(4)` 状态位 → `0x43E697` 取攻击力 → `div 10` → `add eax,4`。
  3. `0x4CF398` 命中装备特效则 `shl [ebp+8],1`（获取量翻倍）。
  4. 写 `0x501C00+编号`，到顶写 200（`0x4D420C`/`0x4D4215`）。
- `.data` 区有一份同构副本 `0x4A6F60`，但它调 `0x3D8xxx`（不可执行）⇒ 死数据。

**为什么每关不清空**

- `0x415ACB`：循环 `0x40CBF0(i,0)` 清单位 0..0xFF，然后 `mov ecx,0x501b00` 循环 `0x140` 次写 0 ⇒ 清 `0x501B00..0x501FFF` 共 `0x500` 字节（正好覆盖 SP 数组）。
- 但**全文件对 `0x415ACB` 的引用为 0**（`E8/E9` 字节扫描 + dword 指针扫描都是 0）⇒ 死代码。
- 覆盖探针实测印证：开战瞬间（帧 10）一次性装载 163 个非零 SP，之后只增不清。

## 实现/使用方法

**把 SP 当资源用（读/写）**

```asm
mov eax, 编号
add eax, 0x501C00
mov byte [eax], 0          ; 清空该单位 SP
```

**给某人加「开局满 SP」**

在开战路径上写 `byte[0x501C00+编号] = [0x505F74]`（需先调 `0x4D40D0` 算出上限）。

**改集气速率**

挂 `0x4D4160` 内部（在 `div 10` 之后 `add eax,4` 处）改常数，或在洞穴里重算。

## 风险与边界

- **每关清 SP 的全部尝试都失败了**（6 版），失败复盘见 [案例页](../10-制作案例/每关清空SP失败复盘.md)。不要在没搞清真实开战入口前再试。
- 清 `0x501B00..0x501FFF` 会连带清掉 `0x501B00` 的每单位标志块 —— `0x415ACB` 敢这么写是因为它本来就是清场函数。
- SP 上限是**全局单值**（`0x505F74`），只对「当前操作对象」有效；批量处理时必须逐个重算。
