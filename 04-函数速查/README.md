# 04 · 函数速查

> 地址 → 语义 → 调用约定的单页索引；写挂钩前先在这里查「有没有现成的」。

## 这一层讲什么

本库唯一的索引页：知道地址不知道干什么，或者知道要干什么不知道调哪个，都先来这里。

约定简写：`ret N` = stdcall 清 N 字节；`ret` = 无栈参数；开头标 `ECX` / `EAX` 的是寄存器入参。
