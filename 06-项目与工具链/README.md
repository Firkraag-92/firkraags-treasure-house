# 06 · 项目与工具链

> 用哪些脚本干活，以及每次改完必须留下的那份日志。

## 这一层讲什么

工具都在 `脚本目录\`（Python 3，已装 capstone / keystone-engine）。本仓库只记录用法与口径，不随附二进制。

日志纪律是硬要求：没有日志的改动视为没做完。
