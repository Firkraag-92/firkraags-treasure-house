# 07 · 数据表与资源

> 名表、界面文字、形象表 —— 以及它们和用户那套老编辑器之间的关系。

## 这一层讲什么

这一层的共同点是「改完别人也在读」：形象指定器、剧本编辑器都按固定偏移读 exe 与 Data.e5，动了布局它们就废。

安全改文字只有两条路：改名表指针指向新串，或在 `Imsg.e5` 末尾追加记录。
