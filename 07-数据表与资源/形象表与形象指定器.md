# 形象表与形象指定器

## 结论速览

- 三张被编辑器（`形象指定器w61.exe`）直接改写的表：**S 形象表** `0x501000`（file `0xD2800`）、**R 形象表** `0x50F800`（file `0xE1000`）、**兵种相克** `0xA3280`。
- 三张表都在 `.data2` 段内，**与代码洞穴（`.data3`）完全不重叠** ⇒ 我们的补丁与编辑器兼容。
- 形象组由 `0x45362B` **纯按兵科**决定，与地形无关。
- 形象指定器是 VB6 程序，还会处理 `Person.e5`、`Data.e5`（LS 压缩）、`Star.e5`、存档 `Sv??b.E5S`。

## 适用版本

- 6.1 魔改（罡星 117 关实测）。

## 已确认事实

**三张表（117 关 `Ekd5.exe`）**

| 表 | VA | 文件偏移 | 规模 |
|---|---|---|---|
| S 形象 | `0x501000` | `0xD2800` | 1024 word（非零 548，最大 526） |
| R 形象 | `0x50F800` | `0xE1000` | 1024 word（非零 496） |
| 兵种相克 | — | `0xA3280` | 40×40 字节（主体 `0x64`=100%，个别 `0x5A`/`0x96`） |

**形象指定器**

- 文件 `117关工作目录\形象指定器w61.exe`，1,085,440 B，md5 `e6114f9ef030c8ee5e9882d30e3b150b`，PE 时间戳 2016-11-17，**VB6**（导入 MSVBVM60.DLL），无壳。
- 功能：S 形象指定 / R 形象指定 / 形象导出 / **LS 压缩解压 .e5** / 存档编辑 / Pmap 地形 / Data.e5 解压重压。
- 硬编码常量：`0xD2800`（3 处）、`0xE1000`（3 处）。
- `System.ini` 同名键：`FileHead=D2800`、`RFileHead=E1000`、`UserXK=A3280`、`CountSV=800`、`Xgh=72`。

**形象组计算 `0x45362B`（ret 8）**

```
兵科 = 0x47FB13(0x1a) 取 +0x2B
if 兵科 >= 0xD: 组 = 兵科 + 0x1A
else:           组 = 兵科 * 3
if 组 == 0x26: 按 [ebp+0xC] 与 0x28/0x14 比较再加 0/1/2（等级档）
```

- 水寇（15）→ 组 41。**没有任何地形分支**。

**代码引用点**

- S 形象表 `0x501000` 的 6 处代码引用：`0x405368`、`0x4068E1`、`0x417C8A`、`0x41AA48`、`0x420354`（`shl eax,1; add eax,0x501000`）、`0x465DAD`（写）。
- R 形象表经 78 指令（变量赋值）写入：处理器 `0x4CF2DA` → `0x4202FA` 分派，kind==2 时地址 = `0x50F800 + 索引*2`。

## 实现/使用方法

**改形象（让编辑器做）**

用形象指定器直接改，它写的就是上面三张表；改完确认 exe 长度不变（应为 7,413,760 B）。

**用剧本改形象**

```
77:变量运算 整型变量 0 = 常数 <形象号>
78:整型变量赋值 0 ==> <编号> R形象     ; 或 S形象
```
78 的目标属性统计：R形象 1630 次、头象 1507 次，另有辅助/武器/防具/HP/MP。

**兼容性核对**

我们的产物只改 `.text` 挂钩 + `.data3` 洞穴；三张表都在 `.data2`/`兵种相克` 区 ⇒ 不冲突。

## 风险与边界

- 若同时改 `Data.e5` 的人物表布局，形象指定器会读错（它按固定偏移）。
- S/R 形象表是**运行期数据源**，直接改 exe 文件里的副本有效；但要注意游戏可能从 `Person.e5` 再装填（未完全确认）。
- 未实测：形象指定器保存时是「原位改写」还是「整文件重写」。若整文件重写，可能覆盖掉我们挂在 `.data3` 的洞穴。
