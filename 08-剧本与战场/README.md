# 08 · 剧本与战场

> 不改 exe 也能做到的事：剧本指令、改名、列传重定向。

## 这一层讲什么

剧本层是「零字节风险」的通道：`72 16` 写扩展字段、`72 0` 改名、`78` 改形象/装备/HP/MP。

但改 `.eex` 的长度风险极高 —— `eexlib` 自校验能过，用户的编辑器仍可能打不开、游戏可能崩。
