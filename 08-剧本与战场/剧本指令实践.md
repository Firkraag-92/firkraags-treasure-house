# 剧本指令实践

## 结论速览

- 罡星的剧本（`.eex`）里，改人物数据有三条主通道：`72 16`（扩展字段）、`72 0`（改名）、`78`（形象/头像/装备/HP/MP）。
- `72 16 <编号> <字段> <值>`：字段 16..21 = 招式/秘术/合技/异术/…；字段 22/23 = 连击率/暴击率；24 = 属性；25 = 特殊转职；26..30 = 五维成长档；31 兵力档；32 策略档；33 移动力；34 攻击范围。
- 改名不是 `78`，而是「`77` 把编号写进变量 4054 + `72:信息传送 0 <名字>`」。
- 改 `.eex` 长度风险极高：`eexlib` 自校验能过，用户的编辑器仍可能打不开、游戏可能崩。

## 适用版本

- 6.1 魔改（罡星 112/117 关）。

## 已确认事实

**常用指令**

| 指令 | 作用 | 样例 |
|---|---|---|
| `77:变量运算` | 写整型变量 | `77:变量运算 整型变量 4054 = 常数 147` |
| `78:整型变量赋值` | 变量 ↔ 对象属性 | `78:整型变量赋值 0 ==> 109:高俅 R形象` |
| `72:信息传送 16` | 写扩展字段 | `72 16 22 19 103` |
| `72:信息传送 0` | 改名 | 变量 4054 先设成编号，再 `72 0 张三11` |
| `30:武将出现` | 单位出场 | `30:武将出现 121:黑月奴 (52,31) 朝北` |
| `50:战场动作设定` | 指定特殊形象/动作 | `50:战场动作设定 147:高级武术` |
| `52:兵种改变` | 改兵科 | `52:兵种改变 5:林冲 高手` |
| `6c:武将能力复制` | 跨人复制能力 | `6c 29:张顺 → 30:阮小七` |

**72/16 字段与落点**

| 字段 | 落点（扩展行偏移） | 宽度 | 用途 |
|---|---|---|---|
| 0..14 | `+字段*2` | word | 未全部确认，10..14 空闲候选 |
| 16 | `+0x20` | byte | 招式 |
| 17 | `+0x21` | byte | 秘术 |
| 18 | `+0x22` | byte | 合技 |
| 19 | `+0x23` | byte | **异术/特技** |
| 20/21 | `+0x24`/`+0x25` | byte | 未确认 |
| 22/23 | — | byte | 连击率/暴击率 |
| 24 | — | byte | 属性 |
| 25 | — | byte | 特殊转职 |
| 26..30 | — | byte | 五维成长档 |
| 31..34 | — | byte | 兵力/策略/移动/攻击范围 |

**78 的目标属性（全量统计）**

R形象 1630、头象 1507、辅助 14、武器 3、武器等级 1、防具 1、防具等级 1、MP 3、HP 2。**没有「名字」属性。**

**eex 文件结构风险**

- `eexlib` 的 `insert_at` 产物通过 `validate()` 与 `sig()` 校验，但用户编辑器打不开、游戏崩（已发生一次，S_004 加两条 72/0 后）。
- 结论：在查清编辑器兼容性之前，**不要用 `insert_at` 改正式剧本**。

## 实现/使用方法

**给某人加异术**

```
72:信息传送 16
<编号>
19
<异术编号>
```

**同一关内给龙套改名**

```
77:变量运算 整型变量 4076 = 常数 0
77:变量运算 整型变量 4054 = 常数 <编号>
72:信息传送 0 <新名字>
0:事件结束
```

**先确认该单位已加入我军**：编辑器会自动补 `1:子事件设定` / `2:内部信息 给我军改名必须先加入` / `0:事件结束`。

## 风险与边界

- 改剧本长度风险极高；能改 exe 解决的就不要改剧本。
- 变量 4076 在这些行前恒为 0（全工程 848 处都是 0），改它可能改到别的语义。
- 异术是剧情授予 ⇒ 同一人不同关可以是不同值；不要假设「他的异术」是固定的。
