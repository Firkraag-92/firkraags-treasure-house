# 09 · 版本与外部资料

> 别的引擎长什么样，以及我们为什么不能照抄。

## 这一层讲什么

6.1（罡星）、6.5PL（神话三国志）、6.6（star175）、瓦岗（star175 系定制）只共享 KOEI 底座，扩展层互不继承。

跨代真正可复用的是「需求规格 + 工具链 + 挂钩纪律」，不是地址。
