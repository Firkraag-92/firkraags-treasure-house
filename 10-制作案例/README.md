# 10 · 制作案例

> 已经交付并且实机验过的改法，以及刻意留下的失败复盘。

## 这一层讲什么

每个案例都写了挂钩字节、洞穴布局、产物 md5、实测结论，目的是让你能整段复刻或整段搬运到新基底。

失败案例同样是资产：`每关清空SP失败复盘` 用 6 个版本证明旧战斗流程不是真实开战路径。

## 阅读顺序

- 先看与你要改的功能最近的案例，再看它的「风险与边界」。
- 把案例当模板用时，务必重新核对基线 md5 与锚点字节。
