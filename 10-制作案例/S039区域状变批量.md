# 案例：S_039 区域状变批量显示

## 结论速览

- **问题**：S_039 芒砀山降魔有 6 条「`4d 武将状态变更 区域 (0,0)-(27,19) 敌军 全能力上升`」，在 6.5PL 上 2–3 秒播完，在罡星要几分钟。
- **根因**：罡星在循环体里**逐单位阻塞播放**特效（`0x45AE08 → 0x45AA5C → 0x43E6AA → 0x40BCF6/0x452F9D/0x401E5D`），6.5PL 是循环内只收集、循环外播一次。
- **v1（失败）**：拆分「追加」与「播放」，逐条 `count=1` 提交 ⇒ 速度对了，但**图标位置全错**。
- **v2（成功，用户「和 6.5PL 一模一样」）**：改用 `0x45AE08` 自带的收集通道，循环结束后一次 `0x40196F(count, buf, 0)` + 一次 `0x401E5D`。
- **v3（改进未实测）**：修掉 v2 把收集缓冲硬编码成 `0x62B400` 的缺陷（另一个调用者 `0x450EE3` 有自己的数组）。

## 适用版本

- 6.1 魔改（基线 `Ekd500.exe` md5 `6bd4c3ea68e7ad372a581718087ff36d`）。

## 已确认事实

**原始路径**

```
0x4150E7 (4d handler) → 0x415428 区域分支
  mov ecx,0x4B5DF0 ; xor eax,eax ; call 0x45AE08
0x45AE08 双层扫描 → 每个命中单位：
  0x45AA5C → 0x43E6AA → 0x40BCF6 → 0x452F9D → 0x401E5D（阻塞）→ 0x4016CD（复位）
```

- 每次复位 ⇒ 清单永远 1 条、出生累加器归零 ⇒ 位置永远对，代价是 6N 次阻塞播放。

**v1 为什么错位**

- 0x401A7E 是「一次调用 = 一整张列表」：槽号、出生累加器、delay、`0x74` 上限、`0x29C` 时间窗、延后队列全按单次调用算。
- 逐条 `count=1` 把「同一时刻 N 个图标」排成沿时间轴依次出生，播放却只有一趟 ⇒ 位置全错。

**v2 做法**

| 挂钩 | 原字节 | 补丁 |
|---|---|---|
| `0x45AE08` | `55 8B EC 83 EC 34` | `E9 F3 03 1D 00 90` |
| `0x45AF36` | `8B E5 5D C2 1C 00` | `E9 05 03 1D 00 90` |
| `0x43EA7B` | `8B 4D F4 80 F9 FF 74 38` | `E9 80 C8 1E 00 90 90 90` |

- **CAVE_HEAD `0x62B200`（30 B）**：复刻 prologue；`[0x62B500]=1`；`test eax,eax; jnz have; mov eax,0x62B400`（只有调用者没给数组时用洞穴缓冲）；`jmp 0x45AE0E`。
- **CAVE_PRES `0x62B300`（117 B）**：`MODE==0` → 原单发流程；否则图标 `0xFF` 跳尾、`MODE==2` 跳尾、`MODE==1` → `0x40BCF6(0x4917B0,图标号)` 并置 `MODE=2`。
- **CAVE_TAIL `0x62B240`（76 B）**：`MODE==2 且 条数!=0` → `push 0; push 0x62B400; push 条数; ecx=0x4917B0; call 0x40196F` → `push 1; push 0; call 0x401E5D` → `call 0x4016CD`；然后 `MODE=0`、复刻出口。
- 改动 4 段共 **207 字节**；产物长度不变。

**v3 改进**

- HEAD 末尾加 `mov [0x62B504], eax` 记住选定数组；TAIL 改为 `push dword [0x62B504]`。
- 共 212 字节改动。产物 `Ekd500_区域状变批量3.exe` md5 `3c6e0d17e00766449ac40edab8bc5e6c`。

## 实现/使用方法

**同类需求的复用点**

- 只要发现「引擎自带收集通道但调用者传 0」，就可以用同一套路：HEAD 传洞穴缓冲 → TAIL 一次提交 + 一次播放。

**已知取舍**

- 同批所有单位共用一个图标号（符合原设计）。
- 屏幕外单位仍被裁剪。
- `0x450EE3` 这个自带数组的调用者在 v2 下会读错缓冲（v3 修了）。

## 风险与边界

- 三个挂钩必须一起打，只打一个会得到「快但错位」或「慢但正确」。
- `MODE` 是全局量，不可重入；同一帧内嵌套调用会互相干扰。
- 洞穴 `0x62B400` 缓冲只有 `0x100` 字节，条数上限 `0x74`。

## 证据来源

- 产物 md5：v1 `f4b51285…`、v2 `6ea39a12f26934689da867b5fdfc82b4`、v3 `3c6e0d17…`
- 证据等级：v2 实机通过（用户原话「好了，效果非常完美！和6.5PL一模一样！」）；v3 待实测。
