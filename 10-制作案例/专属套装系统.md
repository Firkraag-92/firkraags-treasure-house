# 案例：专属套装系统

## 结论速览

- 给特定武将 + 特定专属武器同时装备时，触发额外效果（如林冲+丈八蛇矛闪避 +30%、秦明+狼牙棒概率破坏防御）。
- 系统从 V1 迭代到 **V9b**，最终版已并入 117 关的 5 项整合（`Ekd5_整合5项_v2.exe`）。
- 设计原则：**不移动游戏自带工具栏按钮**；入口要么自绘、要么放不扰动原布局的位置（用户明确要求）。
- 完整实现细节以原文 `专属套装_v9b改造说明.md` 为准，本页只记知识库层面的结构。

## 适用版本

- 6.1 魔改（罡星）。dev2 基线 `Ekd500.exe`（md5 `6bd4c3ea…`）已含 v9b。

## 已确认事实

- 触发条件 = 「单位编号 + 专属武器 id」双匹配（等价于一个二维白名单）。
- 效果类型：属性加成（闪避/命中）、概率性破坏防御、二次行动、唯我独尊等。
- 后期曾为塞入口而移动工具栏按钮，被用户否决（「太破坏使用手感」）；随后恢复原版 UI，入口改隐藏式。
- 相关产物（112 关期，均在 `112关工作目录\_专属套装补丁\`）：v1 → v2 配方B → v3 配方E → v4 二期按钮 → v5 配方C → v6 二期面板 → v7 动态附加 → v7.1/v7.2 修复闪退与面板关闭 → v8 全量 → v9 全量 → **v9b 全量**（`v9b_full\Ekd500_专属套装v9b_全量.exe`）。
- 117 关期并入 5 项整合（`Ekd5_整合5项_v2.exe`）。
- 相关数据表：`_exe分析\数据表\专属套装规则.csv`（规则表）与 `zhuanshu_table_E.bin`（v9b 备份 `.bak_v9b_20261018`）。

## 实现/使用方法

**新增一个专属套装**

1. 确认触发用的「单位编号 + 武器 id」组合没有被占用。
2. 在挂钩点判组合命中，跳到洞穴执行效果。
3. 效果尽量走引擎现有函数（属性取值 `0x4183F7`、状态施加 `0x40336A`），不要自己算伤害。
4. 存档兼容：不要往单位记录里写新字段（读档会覆盖）；用扩展行或纯代码判定。

## 风险与边界

- 入口 UI 改动会破坏手感 —— 用户红线。
- 效果若挂在「伤害计算」链上，必须同时验证「被格挡」「被闪避」「反击」三种分支（猛击格挡闪退就是这么来的）。
- 多个专属效果叠加时要确认判定顺序（谁先谁后结果不同）。
