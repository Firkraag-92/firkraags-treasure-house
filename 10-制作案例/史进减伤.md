# 史进减伤（受远程伤害 −20%、受策略伤害 −20%）

> 一句话：物理侧挂 0x43BF11（判定用引擎自带 0x43FF9A / 0x4D2138 远程表），策略侧挂 **0x43C318（0x43C00F 的尾部出口，已经是夹紧后的最终伤害）**，两处洞穴都只判「受击方编号 == 0x16（史进）」，命中把伤害压到 80%。

## 1. 结论速览

- 需求：史进（单位编号 22 = 0x16，兵科 74 任侠）受**远程**伤害 −20%、受**策略**伤害 −20%。
- 产物 v8（均 7,413,760 B、段表不变）：
  - `Ekd5_史进减免_v8.exe` md5 `96A351941C445F7BF47A025409572159`（基底 117 关 Ekd5.exe 49A50A0C…）
  - `Ekd5_整合5项_v2_列传2_史进减免_v8.exe` md5 `1EFA52BEB2E95143306CE204BCFE0D01`（基底 整合 v2 列传2 AC0A8747…）
- 两处挂钩共 12 字节 + 两段洞穴（0x63A000 61 B、0x63A200 39 B）。
- **v1..v6 全部作废**：
  - v1/v2 用自维护兵科白名单（漏将军 54 / 任侠 74、误含先锋 66/70/71）；
  - v4 改用 0x4D2138 但把 0x24 战场对象当 0x48 单位记录喂给 0x40BE7D / 0x40BF10，编号算出垃圾 ⇒ 实机「伤害一点没变」；
  - v5 物理侧修对了（实机火器营凌振打史进确实 −20%），但策略侧只缩 0x40D255 的 EAX，反把「攻防差值」分支推大 ⇒ 实机「策略伤害反而增加」；
  - v6 想靠同时缩 [ebp-4]/[ebp-8] 抵消，被 v8 取代（v8 直接挂在策略伤害真正出口，不再参与中间融合）。

## 2. 适用版本

罡星煞曜传 6.1，117 关目录。基底 md5 49A50A0C45FE6C91C9779607868004F0 或整合版 AC0A8747276A30AD14C5F2BE9DEB33CF。

## 3. 已确认事实

| 项 | 值 |
|---|---|
| 史进单位编号 | 22 = 0x16（Data.e5 人物表索引 22，+0x0D = 22，+0x1A 兵种 = 74 任侠） |
| 物理伤害唯一出口 | 0x43BF11（原 6 字节 `8B 45 FC 59 EB 02`） |
| 策略伤害计算函数 | 0x43C00F（`ret 0x10`；ECX=攻击方对象，[ebp+8]=受击方对象，[ebp+0xC]=附加记录，[ebp+0x10]=策略 id，[ebp+0x14]=0 实算 / 非 0 只估） |
| 策略伤害真正出口 | **0x43C318**（原 6 字节 `8B E5 5D C2 10 00` = mov esp,ebp / pop ebp / ret 0x10），已是夹紧上限后的最终值 |
| ★参数类型 | 物理 / 策略两边的单位参数都是 **0x24 字节战场对象**（0x4B2C50+序号×0x24），不是 0x48 单位记录 |
| 物理侧受击方 / 攻击方 | 对象 [ebp+8] / 对象 [ebp-0x2c] |
| 物理侧现成记录 | 受击方记录 `[ebp-0x24]`、攻击方记录 `[ebp-8]`（之后全程只读，不能占用） |
| 策略侧受击方 / 攻击方 | 对象 [ebp+8] / 对象 [ebp-0x18]（后者就是 ECX 传进来的攻击方） |
| 对象 → 编号 | `mov ecx,对象; mov ecx,[ecx]`（对象 +0 = 编号 dword）；也可 `0x40658F` → 记录 → `0x40BE7D` |
| 记录 → 编号 | `push 记录; call 0x40BE7D; add esp,4` → EAX = 编号 |
| 远程判定（吃对象） | `mov ecx,对象; call 0x43FF9A` → AL = 0/1（内部 0x43B4A7 → 兵科行 → `byte[0x4D2138+行]`） |
| 被记为远程的兵科行 | 2 弓兵 / 4 弓骑兵 / 16 弩兵 / 18 将军 / 27 火器营 / 29 连环马 / 34 任侠 |

## 4. 实现·使用方法

### 4.1 挂钩

```
0x43BF11  8B 45 FC 59 EB 02      →  E9 EA E0 1F 00 90   ; jmp 0x63A000（物理）
0x43C318  8B E5 5D C2 10 00      →  E9 E3 DE 1F 00 90   ; jmp 0x63A200（策略）
```

策略侧为什么不挂 0x40D255：那里只是子项融合前的中间值，缩它会改变「攻防差值」的方向，实测反而加伤害。也不挂 0x43C315 / 0x43C312：`0x43C0C9`（早期出口）正好跳到 0x43C318，挂前面会把那条出口踩成半条指令。

### 4.2 洞穴 A（物理，0x63A000，61 B）

```asm
mov eax, [ebp-4]          ; 复刻原第一条（最终伤害）
pop ecx                   ; 复刻原第二条（平衡 0x43BF03 的 push eax）
push dword [ebp-0x24]     ; 受击方记录（框架早已转换好）
call 0x40BE7D
add esp, 4
cmp eax, 0x16             ; 受击方必须是史进
jne done
mov ecx, [ebp-0x2c]       ; 攻击方对象
call 0x43FF9A             ; 引擎自带远程判定（内含 0x4D2138）
test al, al
je done
mov eax, [ebp-4] / xor edx,edx / mov ecx,5 / div ecx
mov ecx, [ebp-4] / sub ecx,eax / mov [ebp-4],ecx    ; damage -= damage/5
done:
mov eax, [ebp-4]
mov esp, ebp / pop ebp / ret 0xC
```

### 4.3 洞穴 C（策略，0x63A200，39 B）

```asm
mov ecx, [ebp+8]          ; 受击方对象
mov ecx, [ecx]            ; 对象 +0 = 编号
cmp ecx, 0x16             ; 必须是史进
jne done
mov eax, [ebp-4] / xor edx,edx / mov ecx,5 / div ecx
mov ecx, [ebp-4] / sub ecx,eax / mov [ebp-4],ecx    ; damage -= damage/5
done:
mov eax, [ebp-4]          ; 复刻原出口
mov esp, ebp / pop ebp / ret 0x10
```

## 5. 风险与边界

- 「远程」= 攻击方兵科被 0x4D2138 记为远程（弓/弓骑/弩/将军/火器营/连环马/任侠）；**按兵科判定、与实际武器和距离无关**。
- 洞穴里绝对不能占用 `[ebp-8]`（物理侧那是攻击方记录指针）。
- 只判受击方编号 ⇒ 史进自己打别人不受影响。
- 策略侧挂在 0x43C00F 尾部 ⇒ **AI 评估与实际结算都会看到 −20%**（两者用同一函数），这是优点（AI 不会误判），也意味着 AI 会因此更不愿意拿策略砸史进。
- 0x43C00F 同时服务治疗/异常类策略（入口按 `0x449BAC(id) || id==0x15 || id==0x16` 分流）；**若补给类策略也走这条出口，给史进补血/上 buff 也会变弱**（未实测）。若有问题，在洞穴 C 加「策略 id 白名单」判断。
- 取整：伤害/5 向下取整 ⇒ 小伤害减 0。
- 与张顺天运（0x43F8B4 / 0x43D4A0 / 0x630000 / 0x630100）、列传重定向（0x4784C7 / 0x639000）、区域状变（0x62B2xx）、猛击盾反（0x628000 / 0x62A000）、Z 加速（0x62B000）地址无重叠。
