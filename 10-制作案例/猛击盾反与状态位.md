# 案例：猛击 / 盾反与状态位

## 结论速览

- 罡星的状态是**位掩码**，存在战场对象 `+0x1E`（不是单位记录），一位一状态。
- 猛击 = 写 `0x08`（混乱）；盾反 = 写 `0x02`（麻痹）；施加统一走 `0x40336A`（`or al,[ecx+0x1E]`），清位走 `0x418DA0`。
- 最容易踩的坑：把 `0x24` 字节的**战场对象**喂给只吃 `0x48` 字节**单位记录**的 `0x40BE7D`，会返回垃圾，表现为「盾反一次都不触发」。
- 合并到新 exe 时漏搬第二段代码（`0x62A000`）会导致「攻击被格挡就闪退」。

## 适用版本

- 6.1 魔改（罡星 112/117 关）。

## 已确认事实

**状态字节口径（战场对象 `0x4B2C50 + 序号*0x24`）**

| 位 | 状态 |
|---|---|
| `0x02` | 麻痹 |
| `0x04` | 禁咒 |
| `0x08` | 混乱 |
| `0x10` | 中毒 |
| `0x20` | 怯力 |
| `0x40` | 无名 |
| `0x01` | 伴随标志位 |

- `0x7E` = 清全部六位。
- 施加：`0x40336A`（先过 `0x65` 免疫异常判定）。
- 清除：`0x418DA0`，参数 = 掩码按位取反。
- ⚠ `0x30` **不是**混乱掩码 —— 它是「异常持续回合」2-bit 位段（`0x4240CE..D1` 存 `03/0C/30/C0`）里混乱项的默认值 3。实机写 `0x30` 显示「中毒+怯力」。

**猛击/盾反的代码位置（117 基底）**

- 第一段 `0x628000..0x628EA6`（猛击）。
- 第二段 `0x62A000..0x62A56E`（1095 B，盾反）。
- 挂钩点 `0x4059F4` 原字节 `0f 84 87 00 00 00`（`je 0x405A81`）→ 换成 `E9 … 90` 跳 `0x628600`。
- `0x628600`：`cmp dword[ecx+edx*4+0x254],0` / `jne 0x62865C`（正常路径 `jmp 0x4059fa`）；等于 0（格挡）→ `jmp 0x62a000`。

**两个遗留调试日志器**

- `0x628534` 与 `0x62A52F`：`pushal` 后 `CreateFileA(本机日志\gx_muji_log.bin)` + `WriteFile(0xC0)` + `CloseHandle`；`0x62A000` 段内被 call 9 次。
- 处理：首字节 `60`(pushal) → `C3`(ret) 停用。

## 实现/使用方法

**挂钩纪律（这个案例是反面教材）**

把一条 `call` 改成 `jmp` 跳自写补丁时，补丁交还原例程前必须自己 `push` 原 call 的返回地址（挂钩地址 + 5，如 `0x405A7C` → `push 0x405A81`）再 `jmp` 原调用目标。
否则原例程 `ret` 会弹出垃圾地址 ⇒ 走到该挂钩点就必闪退。

**给某个单位加状态**

```asm
; ecx = 0x4B2C50 + 序号*0x24
push 0x08                  ; 混乱
call 0x40336A              ; 施加（内部先做免疫判定）
```

## 风险与边界

- 状态位在战场对象上，**不在**单位记录 `+0x1E`（那是另一套）。
- 从记录取编号用 `0x40BE7D`，从战场对象取编号必须先经 `0x4061F9` 转成记录。
- 「异常持续回合」与「状态位」是两套数据，写状态位不会自动设回合数。
