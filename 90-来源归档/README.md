## 这一层讲什么

本库所有结论都来自 `112关工作目录\_exe分析\` 下的原文（逐日逆向流水、指令拆解、修改手册等），按主题重组；原文保留不动。

这一层给两类人用：想追证据的人（原文索引），和想避免重复踩坑的人（失败台账）。
